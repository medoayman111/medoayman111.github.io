2. Description of the Service

Lingoa provides educational English vocabulary learning tools designed around the Oxford 3000 corpus, modern memory science (Free Spaced Repetition Scheduler - FSRS), real-world native video pronunciations, contextual stories, interactive flashcards, speaking evaluations, and Android home-screen widgets.

The core learning database operates on an offline-first architecture, storing study progress on the user's local device without mandatory account creation.
